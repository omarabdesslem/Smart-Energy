# Fixed-view fallback house image

Asset: `apps/web/public/images/house-3d.png` (1536 × 1024 PNG).

Generated with the built-in image generation tool for the earlier fixed-image prototype. The current interface uses an actual Three.js house with a perspective camera and orbit controls. This single image is used only for the explicitly labeled fixed-view fallback when a browser cannot create a WebGL context.

This archived asset is a fixed architectural render. The current 3D model is defined in `apps/web/src/house-model.ts` and does not depend on image coordinates.

## Final generation prompt

Use case: stylized-concept. Asset type: the single house image in an interactive solar roof designer website. Primary request: a precise, elegant monochrome 3D architectural render of one detached two-storey European house, viewed from an elevated orthographic three-quarter angle so one large uninterrupted rectangular sloped roof face is very clearly visible. Minimal white stucco walls, restrained dark window frames, subtle grey standing-seam roof, small white base slab. Simple gabled roof: ridge from upper left toward upper right, one large roof plane faces the viewer, a smaller side gable wall on the right. Roof must be completely empty, uniform, planar, without chimneys, dormers, skylights, solar panels, trees or obstructions, so interactive solar panels can be overlaid later. House centered and isolated on a pure white seamless background with very soft ambient contact shadow. High-end 3D clay architectural visualization, crisp edges, realistic soft studio lighting, white, black and neutral grey only. Landscape composition, house occupies roughly 80 percent of image width, generous white margin. No text, labels, UI, logos, people, extra images, vegetation or scenery. Draw a real dimensional house, not a flat icon.
